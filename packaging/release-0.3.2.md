## 本版修复

- 修复 Windows 托盘图标正确、任务栏却仍显示 Flutter 图标的问题。
- 正式版窗口、通知、开始菜单和桌面快捷方式使用一致的应用标识和图标。
- 调试版使用独立的任务栏标识，不再覆盖正式版入口。
- 安装及启动时迁移本应用遗留的冲突快捷方式，不删除其他应用入口或聊天数据。
- 显式设置窗口大小图标，并在 DPI 变化时更新。

Windows 用户退出当前客户端后，运行新版 Setup EXE 覆盖安装即可。
本版不改变 Schema V6 或网络协议，仍可与 0.3.0、0.3.1 客户端互通。
不包含尚在规划中的聊天附件交互改版及 0 B 传输问题修复。
