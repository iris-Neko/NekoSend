## 四平台文件粘贴与附件草稿

- Windows / Linux 支持 Ctrl+V，macOS 支持 Cmd+V；Android 支持前台粘贴可读取的文件 URI。
- 文件、文件夹和图片先加入会话草稿，可附带文字，点击发送后依次入队为独立消息；不再选完直接发送。
- 粘贴按钮与快捷键共用同一流程，文字按当前选区插入，不覆盖异步等待期间的新输入。
- 草稿只在本次运行中保留，切换会话不串发；移除可取消准备，部分提交失败只保留未成功的项目，重试不重复提交成功项。
- Windows 位图转 PNG；Linux Flatpak 使用文件门户；Android 保留具体文档目标，不把子文件误当成授权根目录。
- 小屏键盘弹出时保留附件数量和移除入口，避免附件预览挤出输入框。
