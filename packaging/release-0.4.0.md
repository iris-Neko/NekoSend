## 聊天框粘贴与附件草稿

- Windows / Linux 使用 Ctrl+V，macOS 使用 Cmd+V，将复制的文件、文件夹或图片加入当前聊天草稿；文字粘贴仍按光标和选区处理。
- Android 支持前台粘贴可读取的剪贴板文件 URI，并将临时文件准备为稳定发送源。没有提供 URI 或没有权限的文件管理器，请使用附件选择器。
- 输入栏显示附件预览、准备进度和移除按钮。可附带文字，一次点击后依次提交文字和各附件，仍为独立消息。
- 草稿按会话隔离，仅在本次运行中保留；切换会话不串发，退出后不恢复未发送草稿。
- 发送失败保留尚未提交的项目，重试复用操作 ID，不重复发送已提交的文字和附件。
- Windows 剪贴板位图保存为 PNG；文件列表优先于附带的文字。普通文件不受剪贴板图片的 20 MiB 上限限制。
- Linux Flatpak 支持文件传输门户，不扩大到整个主目录的访问权限。

本版只增强输入侧，不包含接收端下载/复制图片交互改版，也不宣称修复所有 0 B 传输故障。
网络协议与 Schema V6 不变，仍可与 0.3.x 客户端收发已有消息类型。iOS 暂不支持。
macOS 真机权限和具体第三方文件管理器的剪贴板兼容性仍欢迎社区测试。
